# Organizador e Separador de Arquivos Automatizado

Script em Python desenvolvido para organizar arquivos em diretórios categorizados com base em suas extensões.

# Tecnologias Utilizadas
- **Linguagem:** Python
- **Módulos Nativos:** `pathlib`, `os`, `shutil`

# Funcionalidades
- Leitura dinâmica do diretório informado pelo usuário.
- Mapeamento automático de extensões para pastas correspondentes (Documentos, Imagens, PDFs, Planilhas, etc.).
- Validação de existência de diretórios para evitar sobreposição de arquivos.
